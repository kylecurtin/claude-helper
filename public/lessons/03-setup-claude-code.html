Lesson · 15 minutes

Install Claude Code & link GitHub.

Cost · $0 to install Needed · Pro or Max, a terminal Difficulty · we take it slow

Claude Code is Claude that lives in your terminal — a text-based window on your computer. You type in plain English, and it reads, writes, and runs code with you. Once you've used it, ordinary text editors feel a little lonely.

Before we start

  • You need a Claude account (Chapter 01) and the Pro or Max plan (Chapter 02).
  • You need a terminal. Mac has one called Terminal (search Spotlight). Windows has PowerShell or the WSL Ubuntu terminal. Linux folks, you know where yours is.
  • You'll want a GitHub account — free at github.com. Make one now if you haven't.

Step 1 — install Claude Code

Open your terminal and paste this:

curl -fsSL https://claude.ai/install.sh | bash

Press Enter. The installer downloads Claude Code and adds the claude command to your computer. When it finishes, close the terminal and open a new one (so it picks up the new command).

Prefer npm? If you already have Node.js installed and prefer that route: npm install -g @anthropic-ai/claude-code works too.

Step 2 — sign in

In your terminal, type:

claude

The first time you run this, it opens a browser tab and asks you to sign in. Sign in, approve the connection, and return to the terminal. You'll see a friendly prompt waiting for you.

Step 3 — install the GitHub CLI

Claude Code talks to GitHub through a small tool called gh. Install it once and forget about it:

  • Mac: brew install gh (you'll need Homebrew — see brew.sh if you don't have it).
  • Windows: winget install --id GitHub.cli
  • Linux: follow the instructions at cli.github.com.

Step 4 — link your GitHub

Still in your terminal:

gh auth login

Choose GitHub.com, choose HTTPS, and let it log you in through your browser. Done — your computer is now allowed to talk to your GitHub.

Step 5 — your first real Claude Code moment

Make a folder for your first project, walk into it, and start Claude Code:

mkdir hello-claude
cd hello-claude
claude

When Claude Code is running, try a friendly first prompt:

"Create a tiny webpage that says hello, with a soft background color and a nicer font than the default."

Claude will think for a moment, then write the file. Open it in your browser. See something you'd change — bigger heading, different color, add a button — and tell Claude. Watch it edit in place. That's the loop.

Where to go from here

You did it. You have an account, a plan, Claude Code on your machine, and a GitHub link. That's the whole 0-to-1.

For 1-to-100, just use it. Ask Claude to help with anything text-shaped: writing emails, planning a trip, organizing a spreadsheet, building a website, learning a language. The more specific you are about what you want and what you don't, the better the answer.

Welcome to the workflow.
