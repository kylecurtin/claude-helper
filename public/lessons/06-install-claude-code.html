Lesson · 15 minutes

Install Claude Code & link GitHub.

Cost · $0 to install Needed · Pro or Max, your terminal, your GitHub Difficulty · we take it slow

Claude Code is Claude that lives in your terminal — the text-based window you opened in the last chapter. You type in plain English, and it reads, writes, and runs code with you. Once you've used it, ordinary text editors feel a little lonely. This is the chapter where everything starts clicking together.

Before we start — your checklist

  • A Claude account on Pro or Max (Chapters 01 + 02). ✅
  • A GitHub account with at least one repo (Chapter 04). ✅
  • A ~/claude/hello-claude folder on your computer (Chapter 05). ✅
  • Your terminal open. ✅

Step 1 — install Claude Code

In your terminal, paste this and press Enter:

curl -fsSL https://claude.ai/install.sh | bash

The installer downloads Claude Code and adds the claude command to your computer. When it finishes, close the terminal window and open a new one (so it picks up the new command).

Prefer npm? If you already have Node.js installed and prefer that route: npm install -g @anthropic-ai/claude-code works too.

Step 2 — sign in

In your new terminal window, type:

claude

The first time you run this, it opens a browser tab and asks you to sign in to your Anthropic account. Sign in, approve the connection, and return to the terminal. You'll see a friendly prompt waiting for you. Type /exit to close it for now — we have more setup to do first.

Step 3 — install the GitHub CLI

Claude Code talks to GitHub through a small tool called gh. Install it once and forget about it:

  • Mac: brew install gh. (Need Homebrew first? See brew.sh.)
  • Windows: winget install --id GitHub.cli
  • Linux: follow the instructions at cli.github.com.

Step 4 — link your GitHub

Still in your terminal:

gh auth login

Choose GitHub.com, choose HTTPS, and let it log you in through your browser. Done — your computer is now allowed to talk to your GitHub on your behalf.

What just happened: you proved to GitHub that this computer is really yours. From now on, Claude Code can read your repos, push commits, and create new repositories — all with your permission.

Step 5 — your first real Claude Code moment

Walk into the project folder you made in Chapter 05 and start Claude Code:

cd ~/claude/hello-claude
claude

When Claude Code is running, try a friendly first prompt:

"Create a tiny webpage that says hello, with a soft background color and a nicer font than the default. Then open it in my browser."

Claude will think for a moment, then write the file. It may ask permission before doing anything — say yes. Open the page, see what it made, then tell Claude what you'd change: bigger heading, different color, add a button. Watch it edit in place. That's the loop.

Try this now Ask Claude Code: "Make a private repo on GitHub called hello-claude, push everything in this folder to it, and give me the link." Claude will use the gh tool we just set up. In under a minute, you'll have a real GitHub repo connected to your real computer, set up entirely by Claude.

Where to go from here

You did it. You have an account, a plan, a GitHub, a terminal, a Claude folder, Claude Code on your machine, and a GitHub link.

For 1-to-100, just use it. Ask Claude to help with anything text-shaped: writing emails, planning a trip, organizing a spreadsheet, building a website, learning a language. The more specific you are about what you want and what you don't, the better the answer.
