Lesson · 10 minutes

Open your terminal & set up your Claude folder.

Cost · $0 Needed · your computer Difficulty · gentle, with a leap

Every computer you've ever used has a hidden text-based interface behind its friendly windows and icons. It's called the terminal, and it's been there all along. We're going to open it for the first time and use it to set up a tidy home for every Claude project you'll ever make.

What is a terminal?

A terminal is a window where you type commands and your computer does what you tell it. No mouse, no buttons — just text in, text out.

It feels old-fashioned because it is. It's also the fastest way to do many things on a computer, and it's how Claude Code works. Don't let it intimidate you. It's just a window that listens.

Open it

  • Mac: press ⌘ + Space, type "Terminal", press Enter.
  • Windows: press the Windows key, type "PowerShell" or "Terminal", press Enter.
  • Linux: you already know.

A window opens. You'll see something like a $ or > symbol with a blinking cursor. That symbol is the prompt — your computer is patiently waiting for you to type something.

Three commands to know forever

Type each of these and press Enter. (Don't paste them all at once — one at a time.)

pwd

Short for print working directory. It tells you where you are right now. You'll see a path like /Users/yourname. That's your home folder — the starting point.

ls

Short for list. It shows what's in the current folder. You should see things like Desktop, Documents, Downloads — the same folders you see in Finder/Explorer.

cd Desktop

Short for change directory. This walks you into your Desktop folder. Run pwd again and you'll see the path has changed.

To go back up one level: cd .. (two dots means "the folder containing me"). To go all the way home: cd ~ (the tilde means "home").

Those four commands — pwd, ls, cd, cd .. — are 80% of what you need to navigate. The rest is just practice.

Try this now Walk into your Documents folder with cd ~/Documents. Run ls. Walk back home with cd ~. Run pwd to confirm. You've now used the terminal more than 90% of computer users ever do.

Make your Claude folder

Here's the habit I'd recommend forming on day one: a single parent folder called claude in your home directory, holding every project you do with Claude. Inside that parent, one folder per project.

In your terminal, make sure you're home with cd ~, then type these three commands one at a time:

mkdir claude
cd claude
mkdir hello-claude

What just happened:

  • mkdir claude — made a new folder called "claude" in your home directory. (mkdir = make directory.)
  • cd claude — walked into it.
  • mkdir hello-claude — made your first project folder inside.

Why this matters

Software people are nearly religious about file organization. The reason is dull but real: it pays dividends every single day. The claude/project-name pattern means:

  • Every project is self-contained. Nothing leaks between them.
  • Claude Code, when you run it inside a project folder, only sees that project. No accidental edits to other work.
  • A year from now, you can find anything in two seconds: cd ~/claude/the-thing-i-made.

Make a new folder for every new project. Always. Future you will be grateful.

Try this now Make a second project folder. From inside ~/claude, type: 
mkdir my-second-project
cd my-second-project
pwd
You should be inside claude/my-second-project. You now have a parent folder, two project folders inside it, and the beginning of a habit that will keep your life tidy.
A small joy: in a year, when you have a dozen projects in your claude folder — each one a thing you made, each one with its own commit history — you'll feel something pleasant. The feeling is called accumulation, and it's one of the underrated rewards of doing things in writing.
